レシピ帳 PWA v1

主な機能
- スクリーンショット画像を複数枚登録
- 料理名・タグ登録
- 料理名 / タグ検索
- タグ絞り込み
- お気に入り登録 / 絞り込み
- 新しい順 / 名前順 / お気に入り順
- レシピ詳細表示
- 編集 / 削除
- IndexedDBに端末内保存
- 画像は長辺1800px程度に圧縮して保存
- PWA対応 / オフライン表示対応

使い方
1. GitHub Pages / Netlify / Cloudflare PagesなどHTTPS環境に配置してください。
2. スマホのブラウザで開き、「ホーム画面に追加」するとアプリのように使えます。
3. レシピ画像データはブラウザ内に保存されます。

注意
- ブラウザのサイトデータを消すと登録したレシピも消えます。
- 別端末には自動同期されません。
- OCR機能はv1には未搭載です。
